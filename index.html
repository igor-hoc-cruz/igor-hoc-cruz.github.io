Email deliverability at scale

Live

Problem

High email volume with a high bounce rate, and a domain with a duplicate DMARC record that cancelled out its protection policy.

What I did

Backed up the DNS, merged the DMARC records, set up a custom return path and suppressed thousands of invalid addresses and problem domains from the lists.

Result

Sender authenticated on SPF, DKIM, DMARC and return path, with domain warm-up held at its limit of 14,000 sends a day.

  • GoHighLevel
  • Zoho Marketing Automation
  • Cloudflare DNS
  • DMARC · SPF · DKIM

Ad leads that vanished before becoming deals

Live

Problem

Half the leads from one Meta campaign never became deals: the CRM silently rejected anyone whose phone number was already on file.

What I did

Traced the runs in n8n and rebuilt the route with duplicate handling, re-entry by the new product, alerts and the company's official lead-entry field standard.

Result

The lost leads were recovered as deals, every failure now raises an alert, and all sources send channel, UTMs and ad IDs.

  • n8n
  • Zapier
  • Zoho CRM API
  • Meta Lead Ads

Lead source and cost per channel

In progress

Problem

Almost no lead reached the CRM with a recorded source, so there was no cost per lead or per customer for any channel.

What I did

Found the cause: the quote form runs inside an iframe that never receives the page's UTMs. Designed a separate, read-only flow that classifies each lead's channel.

Result

Classification logic built and tested, writing to Zoho Analytics, without changing any flow already running in production.

  • n8n API
  • JavaScript
  • Zoho Analytics
  • Automated tests

A 3D desktop character that runs fully offline

Personal project

Problem

I wanted to learn real-time 3D and speech end to end: an animated character on the desktop that reacts and talks, with no paid APIs or cloud services.

What I did

Built an Electron app that renders a VRM character with three.js, with about 300 scripted actions and 98 motion clips, plus a close-up face view that syncs lips, blinks and gaze to the voice. A Python pipeline drives Blender to render animation sets.

Result

Everything runs on a laptop: speech is generated locally with an open-source text-to-speech model, and the face animates in sync with it in real time.

  • Electron
  • three.js · three-vrm
  • Blender Python API
  • Kokoro TTS
  • Node.js

How I work

Principles behind every case

Don't break what already works
